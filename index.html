How it works

Local model. Private network.
It calls you.

01
🔐

Device-Bound Auth

A P256 key pair is generated in your iPhone's Secure Enclave during a one-time QR pairing ceremony. The private key never leaves your device. The server recognizes only this phone — no credentials, no tokens, no password resets.

02
🌐

Private Tunnel

Requests travel through a WireGuard mesh (Tailscale) to your Mac Mini M4. No public IP, no cloud relay. Nginx terminates mTLS — if the device certificate is absent, the connection is dropped before the app sees it.

03
⚡

Herald Calls You

The proactive engine monitors your academic context. Exam in 2 hours with no study session logged? It fires an APNs push. Your phone rings. Herald briefs you. You respond verbally. It acts — fully local, zero cloud.

CryptoKit

A P256 key pair is generated inside the Secure Enclave at first launch. The private key is hardware-bound — not even the app can export it. Authentication is cryptographic proof-of-device, not a credential that can be phished or stolen.

API: SecureEnclave.P256.Signing via CryptoKit · Inspiration: serial part tracking in military aircraft maintenance

mTLS URLSession
Client cert + server cert pinning
Auth at handshake — before app
TLS 1.3

Every outbound request uses URLSession configured with the client certificate from Keychain. Nginx validates the cert before the connection reaches FastAPI. Invalid or absent cert = TLS handshake failure — the agent never sees the request.

Protocol: TLS 1.3 · Client auth: device-bound P256 cert · Server auth: certificate pinning

Zero Trust

Tailscale builds a WireGuard mesh between enrolled devices. The Mac Mini has no public-facing IP — it's only reachable from enrolled nodes. When a direct path is available, traffic is peer-to-peer. Tailscale's relay servers never see payload content.

Protocol: WireGuard (UDP) · Key rotation: automatic · Relay: DERP (fallback only)

TLS 1.3

ssl_verify_client on — Nginx validates the client certificate on every request. Without a valid device cert signed by the pairing CA, the TLS handshake fails and FastAPI never receives the connection. This is the second auth layer after WireGuard.

Config: ssl_verify_client on · ssl_verify_depth 2 · Protocol: TLS 1.3 only

MLX Framework

MLX is Apple's array framework built for Apple Silicon's unified memory architecture. LLM weights and compute share the same memory pool — no PCIe bus overhead. Llama 3.1 8B achieves <2s first-token latency on M4. Zero cloud calls, zero API costs.

Models: Llama 3.1 8B, Mistral 7B · Backend: MLX · Hardware: Mac Mini M4 16GB unified memory

The differentiating feature

The agent calls you.

Every other AI assistant waits for you to remember to ask. Herald doesn't wait.

The Proactive Event Engine runs continuously on your Mac Mini, watching your academic context — calendar events, reminders, study logs. When it detects a trigger condition, it acts without being asked.

Privacy model

Not policy. Architecture.

The privacy guarantee in Herald is not a terms-of-service commitment. It's structural. There is no third party in the chain because there is no third party in the architecture.

The authentication model is inspired by serial part tracking in military aircraft maintenance — where specific components are permanently tied to a specific airframe in a way that is traceable, accountable, and non-transferable. Herald applies the same logic to device identity: a P256 key pair generated in the iPhone's Secure Enclave. The server and the device recognize only each other. No intermediary. No third party to trust, subpoena, or breach.
